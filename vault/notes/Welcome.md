# Welcome

This is **Scrinium** - your own lightweight notes app.

- Click a note in the sidebar, or hit **+** to create one.
- Formatting like `**bold**`, `*italic*`, and `` `code` `` renders live -
  click into a line to see the raw markdown, click away to see it rendered.
- Task list:
  - [ ] Try checking this box
  - [x] Already done

Files are stored as plain `.md` on disk under your `VAULT_DIR` - nothing
proprietary, nothing you can't open in any other markdown editor.
